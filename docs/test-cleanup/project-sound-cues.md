# Project sound cues and ranking cleanup

Completed scope: 14 test files, 207 original test declarations (217 executed cases when the existing 11-edit matrix is expanded). The shared 161-line sound-cues-fixtures helper was checked for callers and remains in use. No dependency, snapshot or fixture file is removed. The table below records every original declaration; parameterized rows apply to every named data case.

Behavioral bar: for every surviving row, (1) the independent source is the file section’s spec/work-note; (2) the named scenario is the externally observable regression; (3) its oracle is a handwritten vector, documented numeric/configuration value, or stated mathematical/repair invariant, with refinements noted in the row; (4) the listed public seam is observed; (5) internal identifiers/collaborator shapes are not part of that observation, so behavior-preserving refactors survive; and (6) the file-specific ownership note and row identify the unique failure not superseded by transport/UI/worker coverage. DELETE rows explicitly name the failed bar. CONSOLIDATE rows name the surviving owner.

No production behavior changed. The only production edit removes an internal handler re-export with no production importer; the actual public sound/pitch module and engine callers remain. Removed test infrastructure includes shared-oracle random-library/request generators, a replay-only undoRedo helper, an empty Map helper and a test-file type re-export. Unused FPS/FLICKS exports in the shared test fixture are now internal constants.
