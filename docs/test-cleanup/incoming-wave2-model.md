## Behavioral basis

Sources: [audio crossfades](../wp-notes/audio-crossfades.md) (documented and explicitly labelled model assumptions), [browser audio](../wp-notes/wma-preview.md) (shipped demuxer/decoder compatibility), [Crop](../wp-notes/crop-order.md), [project persistence](../project-files.md), [fonts](../wp-notes/fonts.md), [Link Media](../wp-notes/link-media.md), [spatial points](../wp-notes/spatial-points.md), [Smooth Slide](../wp-notes/smooth-slide.md), and S01 command/undo contracts and AGENTS§0/§4/§6. Production owners were read alongside tests: `audio-fade.ts`, `audio/browser-codecs.ts`, `render/crop.ts`, `font-usage.ts`, `relink/{paths,plan,command}.ts`, `keyframes-spatial.ts`, public layer/effect resolution, transition commands/invariants and `session.ts`'s single generic before/after history path. No shipped migration changed.

For every retained row the six requirements apply together: (1) its source above independently defines the named result, including labelled supported model choices; (2) the row states a recognizable user/caller failure; (3) expected literals, physical laws, generated input names, pre-action state or independent numerical integration can disagree with production; (4) it observes serialized format, public command/parser/resolver or shared numerical boundary used by production; (5) outcomes survive identifier/helper/algorithm refactors; (6) each row names the input/transition that other retained rows do not supersede. Codec matrix rows protect lookup, media rows protect kind/stream selection, and engine/browser routes protect wiring; these are distinct failure modes. Numerical math owns continuous domains cheaply, while rendered pixel/artifact owners own actual GPU/export application. Merely agreeing implementations and intermediate representations were removed.

The `0.25 px` spatial comparisons use the already documented S03:KF-031 physical numerical bound. Earlier resolver/quad checks compared with production `evaluate` itself at decimal equality; replacing that circular answer with independent de Casteljau plus 100,000-step pixel arc integration establishes a physical oracle. It does not relax an earlier independent physical comparison. The immutable arc table is built once per authored segment instead of once per queried frame. Expected shutter counts are literal documented 1/4/8/16, and exponent/table constants needed only by tests are now private.

Removed unused CPU-only shader reference `smoothSlideContributions`, `smoothSlideCoverage` and its type; these were never called by production. Composition GL now verifies actual pixels against independent physical witnesses. Removed six private shader constants' exports and the pose type export after caller census; actual constants/production uniforms are unchanged. `BROWSER_AUDIO_CODECS` and `fadeShapeExponent` become module-private after their only external test imports disappear. No production behavior changes.
