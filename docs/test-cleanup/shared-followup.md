This audit starts at `8b4c8936`. It revisits 283 named JavaScript/TypeScript test declarations in 52 files, plus the generated interchange fuzz target file (53 Vitest files total), under `packages/{api,config,engine-client,interchange,session,testkit,ui}` and `apps/desktop`, plus the 13 Rust tests under `native/mg`. Parameterized declarations and generated fuzz targets are not runtime-case counts. The prior [shared](shared.md), [formats](formats.md), and [desktop/native](tooling.md) ledgers retain the per-test evidence for unchanged contracts. Decisions below supersede those ledgers only for the named cases. No prior deletion is counted again.

The review reads current tests with their owners and checks live callers. In particular, `big-proposal.ts` remains used by `packages/session/bench/proposals-preview.ts`; it is not orphaned. `segmentedKeyTarget` has one production caller inside `SegmentedControl` and no caller of its export after consolidation. `previewStats` has only project/session test consumers; the project audit removes those counters and their export separately. `ProposalsOptions.clock`, `.sliceMs`, and `.syncItems` have no production or benchmark override caller: remove those three testing overrides, preserving the existing 8 ms/64-item defaults and global clock fallback.
