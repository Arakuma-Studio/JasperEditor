# Project sound test cleanup

Scope: 34 files, 322 executable baseline cases (318 source declarations, expanded table/loop cases). Cue derivation, anchors, ranking, taxonomy, profiles and grammar belong to the separate project-sound-cues audit. This audit read the owned test bodies, public production owners and the independent specifications listed below. No live production behavior changed. The unused English encoding-label helper was removed after confirming that it had no non-test callers. Actual undo/redo remains the packages/session History boundary; replaying a transaction after assigning `h.doc = before` is not counted as undo protection.

## Behavioral-bar interpretation for every surviving row

1. **Independent contract:** the file-specific source is the normative behavior; the case title below names the exact part being exercised. `S12` means [sound-design specification](../specs/12-sound-design.md); `S01` means [document/command specification](../specs/01-project-model-and-state.md). WP references are sections in [sound-design work evidence](../wp-notes/sound-design.md), checked against code rather than accepted as implementation truth.
2. **Real failure:** the per-case expected outcome is caller-visible document data, audio samples, serialized bytes, typed refusal, privacy/approval state or inability to safely load/repair. Its negation is the credible regression identified by the row.
3. **Independent oracle:** literal fixture outcomes, physical sample/flick arithmetic, established musical-key/bar rules, unchanged input snapshots, explicit error codes and specified validity/totality relations can disagree with production. The removed catalogues/source regexes, implementation-derived boundaries and copied score/message structures are not substituted as oracles.
4. **Stable seam:** each file lists the public command, parser, persisted result or PCM API exercised. Private mixer-repair repetition and handler-source parsing are removed.
5. **Refactor resistance:** surviving assertions concern observable results; no DOM/class/source layout, object allocation identity for descriptor no-ops, helper call counts or exact internal key-write counts are required. Structured persisted fields remain because compatibility and restoration are independently specified.
6. **Unique protection:** each row's named scenario is the direct owner of its distinct outcome at the listed seam. Engine/browser tests own transport/rendering/UI integration; they do not supersede the model's refusal, persistence, physical precision or joint-edit invariants. Duplicate command/property executions are explicitly consolidated below instead of retained by that general rule.

All six apply together to each KEEP/REWRITE/OPTIMIZE/surviving CONSOLIDATE row; a test was not retained merely for coverage or a historical label. Setup-only assertions were removed where actual outcomes already prove the contract. Parser/load fuzzing remains required by AGENTS §0.

## Implemented changes and survival evidence

- Removed handler-source message parsing and declaration/label inventories. Actual command/planner translation remains in web `sound-i18n`/`sound-check-model`; seeded finding codes/categories and actual numeric crossings remain in engine `sound-check-p6` and audio-fx `check-findings` (confirmed with their audit owners). The latter pins 5ms entries, 29/30ms decays, 33/100ms music joins and actual click/presence/layer-energy signals. The removed shared heuristic declaration matrix did not run detectors; not every exact internal tuning number is independently pinned by a runtime boundary case.
- Consolidated Auto gain restore/override scenarios into `sound-auto-gain`; consolidated the older pitch scenario into the stronger fractional-pitch boundary sequence, preserving literal positive/negative semitone+cents and typed refusal checks.
- Removed the duplicate <=3-dip hunt run; the original 300-case property, the distinct 12-dip hunt, curved lane properties and saved rounding/zero-depth counterexamples remain.
- Removed the randomized command-layer placement arithmetic replay; direct `peakAlignedStart`/`planSoundInsert` properties retain sample-rate/frame-rate coverage, while focused command placement/pitch and every-rate swap verify wiring.
- Removed pseudo-undo replay blocks across command tests, a dedicated replay-only pitch case and their unused normalizer/run helpers; immutable-input assertions and actual state transitions remain.
- Repaired a vacuous shared-track fallback assertion: A3 previously had no music inside its tested dip span, so `.every` passed an empty list. The fixture now crosses from music into dialogue during the window and checks −18dB music, unchanged 0dB track and dialogue.
- Made End-on-Bar generated cases start in fresh Harness instances from an immutable base; previous cases cannot change later inputs.
- Pinned one-hour padding boundaries at literal 3600/3601s, persisted legacy verdict names and take-id bytes. Strengthened mixer failures to `E_INVALID_PARAM`; model guards compare independent snapshots. Removed descriptor allocation-identity and private repair assertions.
- Removed test-local dead setup/imports and the obsolete source comment naming the deleted source-grep test. Removed `soundCheckAudioLabel`, whose only callers were exact-copy tests: repository-wide searches found no app/package/script consumer. Its encoder reader/key remain live. Shared fixtures remain used; no snapshots, dependencies or configuration became unused.
