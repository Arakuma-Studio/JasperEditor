Counts here are an audit subset, not additional tests for the coordinator to double-count.

Existing read-only, security, journal, storage/parser/fuzz and undo protections were retained.

Each surviving row supplies all six retention requirements. **1** cites the independent source; **2** states the recognizable user/caller failure; **3** identifies authored fixture values/properties as the oracle; **4** names the stable exercised boundary; **5** states the refactor-invariant result; **6** establishes distinct ownership. Exact translations/licenses/config syntax survive where those bytes are themselves the contract.
