# Engine rendering test cleanup

Audit base: `8b4c8936`. Scope: the engine render/export/colour/bake/warp/motion-graphics tests and page-pool, GPU-routing and smart-render owners. Tests that require `REMOTION_E2E=1`, `MG_E2E=1` or the native renderer are included in the source audit; execution is reported separately.

The ledger names every baseline case, including parameter expansions where the runner inventory is available. A retained row's exact behavioral claim is its test name together with the contract, oracle and seam stated for its file. These shared file notes apply to **each** retained row:

1. **Independent contract:** the cited specification/architecture or crash/security rule defines the expectation before the implementation is inspected.
2. **Regression detection:** the named result is observable in the specified artifact, service result or protocol; changing it fails the literal values, error codes or independent relation asserted by that case.
3. **Independent oracle:** fixture-authored frame schedules, literal pixel/format vectors, documented equations, approved goldens, external FFmpeg measurements, or independently required cache/determinism relations. Expected values are not generated by the owner being checked. Preview/export parity is independently required by AGENTS §4; it tests the agreement of distinct execution paths, while the lower math owners protect shared calculations.
4. **Stable seam:** the file notes identify the boundary used. Fault fixtures replace external renderer/filesystem failures; they do not implement the service result being asserted.
5. **Refactor resistance:** retained assertions concern those outcomes, rather than source spelling, DOM trees or collaborator invocation. The SDK option-call assertion and private normalization comparison were removed.
6. **Unique protection:** the named capability, medium, failure mode or external boundary is the differentiating input. Model/command tests cannot prove that FFmpeg actually writes the requested media; rendered pixels do not cover unavailable capability/refusal paths. Pure kernel vectors own transparent/degenerate inputs absent from opaque integration fixtures. The file notes identify deliberate ownership boundaries and consolidation owners.

## Changes

- Consolidate the 15 preset × lossy-codec exports into three real exports covering every target and both MP4/AAC and WebM/Opus muxes. `audio-deliver.test.ts` owns headroom/rate boundaries and direct decoded AAC/Opus delivery. The export owner keeps independent `ebur128` measurement of the muxed file; headroom expectations now use documented literals instead of `codecHeadroomDb` from production.
- Remove the mocked SDK `imageFormat: 'png'` invocation assertion: it observes collaborator shape and cannot prove image fidelity. Retained render parity/stroke/alpha suites measure actual pixels.
- Consolidate the duplicate format defaults into the existing encoder/default export owners, retaining the unique explicit MOV/PCM proxy coercion assertion. Warning codes and interpolation parameters survive; English prose snapshots do not.
- Consolidate shader seed cache protection into `LayerBakeService.planBake` key comparisons rather than serializing `normalisedClip` internals.
- Consolidate each dependent workflow in warp analysis and the dependent master/parity/alpha/cache portion of the first three layer-bake rendering cases into one case; the fresh one-frame contract gets an independent minimal fixture. Their assertions now use local state and can run alone; no later test consumes a previous test's mutable result.
- Decode all requested frame-code strips in one FFmpeg process. Six former local helpers are removed; the shared helper checks process failure and exact output length. Every authored expected frame code remains. The engine media workstream also reuses this helper.
- Reduce the subpixel pan from 300 to 60 full-HD frames, retaining all twenty fractional-pixel phases three times, crossing three whole-pixel boundaries at the same 0.05 px/frame rate, with unchanged RMS, monotonicity, maximum-jump and vertical-drift limits.
- Remove a redundant service-existence assertion and a host-page private-global substring assertion from the bundle HTTP test. Actual HTTP Range/cache/traversal behavior and native/browser rendering owners remain.
- Remove private piece-count ceilings, their 100,000-value allocation and keyframe-count assertions from native animation fixtures; actual curve tolerances, authored geometry and rendering assertions remain.
- Replace page-pool zero-delay timer synchronization with the next event-loop turn and remove the wrapper; grants, progress and cancellation assertions remain unchanged.
- Strengthen effect-mask routing and grading/still path refusals to exact supported paths and typed error codes/field locations; unrelated failures cannot satisfy those checks.
- The measured slowest file was colour-range processing (67.8 s, including 40.2 s for nlmeans). Retain all 18 working-format/range combinations and shorten its colour chart from 30 to 12 frames; S07 §8.5 range fidelity has no 30-frame duration requirement, and the 9-frame temporal denoiser still gets a full window.
- No snapshots, dependencies, generated fixtures or production exports were removed: the affected fixtures and production functions retain other callers. No production behavior changed.
