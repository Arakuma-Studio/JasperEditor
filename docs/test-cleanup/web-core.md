# Web core cleanup: current audit

This ledger reconciles the 16 original core cleanup paths against the current source. It covers 89 original test declarations (loop families are named explicitly); the complementary 30 + 30 paths and their exact per-case evidence are in `web-core-supplement-a.md` and `web-core-supplement-b.md`. Earlier web1–3 reports supply historical evidence; this report records the decisions implemented in this pass.

For each retained row: B1 is the independent source in the file paragraph; B2 is the distinct named failure/input scenario; B3 is the literal fixture, explicit expected result or preserved pre-action document; B4 is the stated caller boundary; B5 means those observable values continue to hold after a behavior-preserving refactor; B6 is the ownership distinction below. Each row names its branch and oracle evidence; shared file facts do not authorize retaining declaration-only probes.

No production behavior is changed. The core-only exports `exportFormatOf`, `SHAPE_HIT_SCREEN_PX` and `ghostCueId` are now private after their test-only importers were removed; legitimate in-module callers remain. Further dead reset/input hooks are recorded in the supplemental ledgers. No fixtures, snapshots, packages or helpers became unused from the core deletions.

Validation and measured timing results are appended after the focused runs. Root owns integrated lint/typecheck/test/build and overall wall-clock measurements.
