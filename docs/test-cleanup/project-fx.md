# FX, transitions and effect presets test cleanup

Scope: all 23 `packages/project/test/{fx*,effect*,transition*}.test.ts` files. Baseline 169 declarations / 182 expanded cases; nine cases removed, leaving 173. Dispositions use the original case identities, with removed and surviving consolidation owners distinguished below. This supplements rather than repeats the earlier `project2.md` audit.

Every retained row explicitly supplies the six bars: **1 source** is an independent requirement/standard; **2 bug** is the caller-visible failure it rejects; **3 oracle** is authored expected data or a mathematical relation rather than a value calculated by production; **4 seam** identifies the stable boundary; **5 refactor** states the behavioral outputs that must stay fixed; **6 unique** explains ownership. Numerical kernel helpers are retained only where they directly encode an independently known mathematical/format contract; authored examples can disagree with the implementation. GL tests observe integration rather than replacing precise high-precision matrix, key-time, protocol or migration vectors.

Changes remove family-private assertion shapes, five declaration/self-comparison tests, a duplicate default-alignment scenario, three redundant dissolve helper scenarios and a false redo replay. Six internal helpers lose export qualifiers because repository-wide caller searches found only same-module production callers after pruning: `ocioTransformOf`, `seededPermutation`, `slowCurve`, `peakTime`, `envelope`, `dissolveMix`. Their implementations and production callers remain. No runtime behavior, dependency, fixture, snapshot or configuration is changed.
