# Web sound test cleanup

Scope: all 38 `apps/web/test/{sound*,audio*}.test.*` files present at 8b4c8936; 315 test declarations (parameterized runtime cases may differ). REWRITE 10; KEEP 261; DELETE 37; CONSOLIDATE 2; OPTIMIZE 5. The report includes deleted tests by their original full names.

The independent sources are repository specifications and historical failures in the sound-design work note, not the implementation under test. Below, each test row names its exact contract/failure; the source and seam paragraphs apply to every row in that file. The retained oracle column records literal/fixture output assertions. For CONSOLIDATE, one removed direct-filter declaration and its surviving timeline-playback owner are counted separately. Engine/device doubles supply external input and do not perform the UI action under test. Unique ownership distinguishes command/panel wiring from the shared project algorithm; duplicated direct placement/track algorithms were removed. Refactor resistance means internal calculations/helpers can change while these externally observed results remain.

Changes: removed the Phase-6 template inventory file, private geometry/copy/menu inventories and duplicated shared placement properties. Removed the shipping audition setter, cache-clear hook, cache-byte getter, trackIsFree wrapper, import reexports and unused internal helper/constant exports. A test-only spy now substitutes the existing public audio-device accessor and always disposes/restores it. No runtime behavior, schema, migration, fixture, snapshot or dependency changed.

Loudness tests now assert real session persistence/undo and a real read-only refusal. The missing-cue negative test checks the specific failure reason and preserves the previous fill target. Reversed mixer sampling keeps its literal oracle and drops the comparison computed with production evaluators. Audition looping uses the specified 250 ms instead of the exported implementation constant; cache eviction observes refetches after six buffers, rather than 48 plays and private byte introspection. Search debounce/listen input setup uses controlled timers.

Validation and timing are recorded below. No CI speedup is inferred from source changes.
