## Isolated-unit failure inventory

- Convolution: transpose the asymmetric kernel; leave the central identity coefficient out. The constant-image GL convolution test cannot distinguish a transpose.
- Transform inverse: invert the translation/rotation incorrectly, swap anisotropic axes, or produce finite-looking output for a singular scale. Current Transform GL cases do not cover anisotropic rotation/singularity.
- Dissolve timing: reverse/nonmonotone progress, move an endpoint when easing/peak/speed changes, shift the wrong peak, or retain effect amplitude at an endpoint. Default-only GL endpoint checks do not exercise all parameter combinations.
- Swish/Flutter timing: shutter span scaled incorrectly for one-sided/custom ranges, or incorrect custom inversion/color schedule. GL keeps representative visible output; these numeric cases cover additional parameter combinations.
- Model parser: invalid indices/counts/offsets, exponential trees or repeated allocations must not crash/exhaust memory. Valid parse tests cannot cover hostile rejection or resource budgets.
- Vector retry: dependency failure must recover geometry in original coordinates, or return safe empty geometry on repeated failure. The mock only throws; the real library still computes every successful boolean.
