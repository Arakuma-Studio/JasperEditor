## Baseline defect found before owner fix

Remote setup failed in the pre-edit run. Inspection found `apps/engine/dist/jasper-proc.mjs` still declares runtime `0.1.0`/recipe `1`, while the merged source declares `0.2.0`/recipe `2`. `ProcessingService.bundleDir` blindly chose that stale development artifact, whereas local `procCommand` already prefers current checkout source. Thus Set up repeatedly installs an incompatible runtime. Fix the setup owner to build the checkout's current source by default; honor explicit JASPER_PROC and keep packaged-install bundle selection. The existing retained setup/probe test detects this caller-visible failure. Risk: checkout setup rebuilds rather than reusing old dist; packaged installs and explicit selection retain behavior. Validate with the retained remote suite after shared-host contention settles.

Independent media inspectors now reject failed FFmpeg/ffprobe commands and empty audio extraction, preventing two failed extractions from comparing equal empty hashes. This strengthens existing media-preservation assertions without new test cases.

Removed the unused `steady-pan.mp4` fixture recipe and its setup dependency: exact steady-frame protection now lives solely in `dejudder.test.ts`, whose lossless fixture permits byte-for-byte verification. The old generated ignored binary is not part of the patch.
