# mg-templates test audit

Pre-edit inventory: five test files, 38 named tests (40 runtime cases because the SVG loop creates two cases per test), and one snapshot file. Test command: `pnpm exec vitest run packages/mg-templates/test`; package typecheck: `pnpm --filter @jasper/mg-templates typecheck`. Independent contracts are `docs/ARCHITECTURE.md` §§10.2, 20.3; `docs/specs/11-animation.md` ATP-001, 003, 004, 006, 009; and `docs/wp-notes/wp-m2-anime-templates.md` FIX-005 review cases. `docs/wp-notes/WP-2G.md` defines the render key.

Baseline paths: `packages/mg-templates/test/anime-contracts.test.ts`, `packages/mg-templates/test/anime-templates.test.ts`, `packages/mg-templates/test/parity.test.ts`, `packages/mg-templates/test/registry.test.ts`, and `packages/mg-templates/test/twins.test.ts`. The table's first column uses those file stems.

Disposition below uses the original test names. For surviving or rewritten tests, the six checks are: independent source, caller-visible failure, expectation independent of code under test, stable public seam, refactor survival, and lowest owner. The **contract** column names the first three, and **seam / ownership** names the last three. All surviving expectations are literals or invariant relations taken from the linked contracts, not copied from the implementation. All surviving tests call public package APIs or the native CLI, and allow internal restructuring. The owning package is the lowest seam except native parity, whose two independently implemented renderers must be compared across the boundary. The native tests require `MG_PARITY=1` and a built `jasper-mg`; their default skip is recorded as a validation risk.

No production export is test-only: `upgradeParams` is called by the registry and documented as a public API; `schemaFiles` is used by the schema generator CLI; math/render helpers are used by shipped templates and `@jasper/motion`. The removed snapshot has no non-test caller. The native JSON fixtures still feed Rust CLI tests. Main risk is that native parity is opt-in and SVG appearance has no pixel-based artifact; those are existing validation gaps, not reasons to retain markup snapshots.

Validation after cleanup: `pnpm exec vitest run packages/mg-templates/test` passed (22 passed, two native cases skipped by the default gate); `MG_PARITY=1 pnpm exec vitest run packages/mg-templates/test/parity.test.ts` passed all four cases with the existing release binary; `pnpm --filter @jasper/mg-templates typecheck` passed; `pnpm exec biome check packages/mg-templates/test docs/audits/test-cleanup-mg-templates.md` passed. Test changes remove 310 net lines, including the snapshot. No production seam was removed; the native fixtures remain in use by Rust CLI tests.
