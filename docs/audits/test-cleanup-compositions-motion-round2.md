## Independent contracts and callers

Read production owners `fonts.ts`, `metadata.ts`, `AssetComposition.tsx`, `pipeline.ts`, `layers/{TextLayer,MotionGraphicLayer,OfflineCard,VideoLayer}.tsx`, `color/{cpu,luts,chain,effects}.ts`, and `mg-host/{protocol,text-probe}.ts`; read S01:RND-002, S03:TXT-005/RND-032, S04:PX-004, S06:LUT-003/CG-004, S11:TXA-004/TXA-010/FIX-003/ATP-010, S08:MGC-037/039 and relevant work-package notes.

Non-test callers: metadata callbacks are registered in `Root.tsx`; `SequenceComposition` is consumed by the Player and engine renderer; video/media routing is used by VideoLayer, AudioLayer, StillLayer and AssetComposition; CPU LUT processing is called by `color/effects.ts`; LUT loading is called by `color/chain.ts`; font readiness is consumed by SequenceComposition and TextLayer; `layerFontFaces` and `fontFormatFromUrl` have no caller outside fonts.ts; `useDocumentFonts` has no caller at all. Text probe APIs are consumed by web CanvasTextEditor, text-measure and bundle-fonts, and the engine bundle text-measure page. No production caller passes `loadLutAsset`'s fetch injection argument.

For each row below, validation is the two package commands above. Risks are low for deletion of private assertions; the explicit exceptions are noted. Every KEEP/REWRITE's numbered explanation corresponds to the user's six bars: independent requirement, visible failure, independent oracle, stable seam, refactor tolerance, lowest nonduplicated owner.

## Planned dead support/seams

Delete text-animation-only fixture builders with that file. Remove font hook/StrictMode/handle-count and face-selection fixtures, font registration count array, `useDocumentFonts` unused wrapper, public exports of same-file-only `fontFormatFromUrl` and `layerFontFaces`, `loadLutAsset` fetch injection argument and test-only barrel re-export. Preserve real runtime functions/callers. Restore text-probe browser stubs and globals between tests. Motion support/seams are listed in its audit.

Baseline: 24/25 cases passed; CPU parity timed out at 8.9 seconds under concurrent host load (5-second timeout). No mismatched color or alpha was reported. This is assertion overhead, not evidence of a product failure; batch the alpha assertions without reducing the 40,000-pixel sample or changing production behavior.

Independent CPU oracle review: `color/cpu.ts` never imports or calls project `applyLut`; it implements its own byte lookup tables, lattice strides, tetrahedron corner selection and RGBA8 output. The oracle is the separate float-based project evaluator. Shared `bakeColorRun` constructs the input LUT only; it does not compute either expected or actual output pixels. This is a differential backend contract, not an implementation calling itself. Preserve all 40,000 sampled inputs and alpha channels.

Inspected the `jasper:color-stage` localStorage override after its E2E writer was removed. `docs/wp-notes/wp-m2-color.md` explicitly documents manual `webgl`/`cpu` selection and real rendering calls `colorStageBackend`. Retained as existing documented runtime configuration under the user's config exception; absence of an automated writer does not establish absence of manual callers.

Final seam inventory before export edits: repository-wide search finds `fontFaceFor`, `repaintFromScratch` and `wantsFullRepaint` called only within their own production modules; their exports formerly exposed private font/repaint test helpers. Remove those exports and the two repaint helper barrel re-exports, preserving FrameRepaint's real callers and all function bodies. Low risk; package typecheck and root gates verify caller closure. These supplement the earlier planned seam removals.
