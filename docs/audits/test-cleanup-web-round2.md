- registerServiceWorker is called by apps/web/src/main.tsx with no argument. SwEnv exported type/injected environment are only testing affordances and will be removed.

- EngineImportService is constructed by SessionServices; project/timeline drop, clipboard and processing use its import/place APIs. wp2e/helpers remains shared by import and UI tests.
- ExportMode/quick export call sanitizeFileName; ExportMode calls encoderOptions. These are production policy seams, not test-only exports.
- DIALOG_ESCAPE_REVERTS is used by actual transition preference fields. Its manufactured primitive test will be deleted, the production contract remains.
- No fixtures/snapshots become orphaned by these selected removals.
