## Contract summary for wave-2 agents

**Documents and commands** (`@jasper/project`)
- Types come from the zod schemas (`Clip`, `Sequence`, `ProjectDocument`…). Unknown clip kinds are typed with the sentinel `kind: '(unknown)'`; detect them with `isKnownClipKind(clip.kind)`.
- Apply edits only through `applyTransaction(doc, {label, origin, commands, sequenceId?, expectedRevision?, dryRun?}, ctx)` or `EditorSession.apply/submit/beginGesture`. The result carries `created/changed/deleted` (clips, tracks, markers, transitions, links, groups, items, media…; a sequence id appears only when its own fields change).
- Handler signature: `(draft, cmd, h: HandlerContext) => result`. Annotate `h: HandlerContext` in object-literal handlers so `h.fail(...)` narrows. Use helpers from `commands/placement.ts` (`clearRange`, `insertShift`, `removeShift`, `splitClipAt`, `setClipRange`, `relinkSplits`, `cleanupSequence`, `syncFollowerTracks`) and `h.frame/h.durationFrames/h.flicks/h.clipContentTime/h.sequence/h.clip/h.track`.
- Id-bearing args (keys ending in `Id`/`Ids`, `target`, `track`, `tracks`) accept temp refs `$name`; `clipIds: '$selection'` and `'$selection.primary'` resolve from `ctx.selection`.
- Content-time math always goes through `contentSpanFlicks` (symmetric rounding) so splits/trims stay consistent; `isThroughEdit` tolerates < ½ source frame.
- Locked tracks never shift (ARCH §2.3); ripple/extract conflicts on sync-locked tracks throw `E_SYNC_CONFLICT` with `blocking` clip ids; `clip.trim {clampToSyncLock: true}` gives gesture behaviour; `syncConflict: 'cut'` removes the conflicting material.
  Only `clip.extract` takes `syncConflict` (the schemas of `clip.place` / `clip.move` list it, unused); `clip.trim` /
  `clip.trimEdits` take `clampToSyncLock`. Each refusal message names what its command accepts — `clip.trim`:
  `clampToSyncLock: true` or `range.extract` over the trimmed frames; `clip.extract`: `syncConflict: "cut"`; the other
  ripples (`gap.close`, `clip.setSpeed`, time-remap ripples): sync lock off or `range.lift` first — and the MCP hint
  defers to it (an agent passed `syncConflict: "cut"` to `clip.trim` on the old hint and got `E_SCHEMA`). Test:
  `packages/project/test/edit.test.ts` "an E_SYNC_CONFLICT refusal names the option of its own command…"; MCP eval case
  `sync-conflict-trim-option` (`apps/mcp/eval/cases/errors.jsonl`).
- After every transaction the invariant checker runs and orphaned synthetics/media are collected (INV-014).
- `ParamPath` ↔ property key helpers: `propertyKeyToParamPath`, `paramPathToPropertyKey`; property specs in `registry/properties.ts` (`storagePath`, ranges, `animatable`).
- `buildRenderSnapshot(doc, seqId, {range?, resolveMedia, resolveFont})` → `RenderSnapshot` (clip `start` absolute; composition renders `range.start + f`); `resolveSceneAt(snapshot, frame)` → layers with `props.matrix` (static clips keep identical `props`).

**Session** (`@jasper/session`)
- `EditorSession.open({store, projectId, ctx, engine})`; `apply(tx)` (sync) / `submit(tx)` (queues during gestures) / `beginGesture(label).update(commands)/commit()/cancel()`; `undo({agent?})`, `redo()`, `jumpTo(i)`; `select(domain, ids, mode)`; `setView`, `setToggles`, `setMediaRuntime`; events `doc.changed`, `selection.changed`, `gesture.changed`, `agent.flash`.
- Repeated user edits merge into one history entry when they pass the same `coalesceKey` within 750 ms.
- `createAutosaver(session, store)` implements S01:PER-020 timing and never saves mid-gesture.

**Engine HTTP** (`@jasper/api`, `apps/engine`)
- Route table `ROUTES` is authoritative for paths; implement a route by replacing `registerStubRoutes([...])` in your plugin with real handlers (`app.jasper.config`, add services to `app.jasper.services`).
- Errors: `sendError(reply, status, code, message, detail?)` → `{code, message, detail?, retryable}`. Upload chunks arrive as a raw stream (`application/octet-stream` parser registered).
- Host check always on (dev also accepts `127.0.0.1:5173`/`localhost:5173`); token mode when `JASPER_LOCAL_TOKEN` is set (Bearer or `jasper_session` cookie; `/health` public).
- Requests with an `Origin` header whose host is not an allowed Host (or the opaque `null` origin) get 403 `FORBIDDEN_ORIGIN` (same-origin only, S04:SC-001). Non-browser clients (agents over WS, Remotion, curl) send no Origin and are unaffected. `startEngine` refuses a non-loopback `--host` unless a token is configured (M1 is loopback only).

**Web** (`apps/web`)
- UI commands: `UiCommand`/`CommandCtx` in `commands/types.ts`; register in your domain module file; ids must match `commands/keymap-defaults.ts` (`DEFAULT_KEYMAP`, `resolveBindings`, `scopeChain`, `chordFromEvent`, `effectiveKey`). A test enforces no duplicate bindings per scope on win/linux/mac/web.
- Panels: replace the component in `panels/<kind>/index.ts` keeping the `PanelDefinition` fields. Cross-panel handles go through `PanelServices` (`register/get/with`).
- Styling: tokens only (`bg-pr-panel`, `text-pr-muted`, `var(--pr-*)`); `pnpm lint` fails on hex/rgb/hsl literals or raw Tailwind palette classes outside `theme/` and `*.tokens.ts`.
