Because a segment follows the interpolation of its *first* key (S01:KF-003), Ease In on a key whose predecessor is `linear` converts the predecessor to `bezier` with linear-equivalent eases (its other segment is unchanged). Auto-bezier eases are stored on every mutation (recomputed when neighbours move); the evaluator still derives them itself. Continuous Bezier sets the other side to the same velocity (slopes scaled by the ratio of the two segments' average speeds). |

## Contracts for other packages

- **Effect drag payload** (`apps/web/src/panels/effects/drag.ts`): `DataTransfer[JASPER_EFFECT_MIME = 'application/x-jasper-effect']` = `JSON.stringify({type: 'jasper/effect', effectId})` plus `text/plain` `jasper-effect:<id>`. Drop targets use `isEffectDrag(dt)` during dragover, `readEffectDragPayload(dt)` on drop and `applyEffectToClips(session, effectId, clipIds, index?)` (one transaction, "Apply <Effect> (N clips)"). **WP-2B** (timeline clips) and **WP-2C** (Program layers) should call these; the integrator may also add `EffectDragPayload` to the `DragPayload` union in `apps/web/src/state/services.ts` (not done here: not in WP-2D's paths).
- **Compositions (WP-2C)**: render effects with `buildPreviewChain(resolvedEffects, registry, uid)` (CSS segments → wrapper `style`; SVG segments → inline `<svg><defs>{markup}</defs></svg>` + `filter: url(#filterId)`). `EffectSpec.preview.css` may now return `null` (use `svgFilter`) or `{}` (identity).
- **Engine export planner (WP-2F)**: `buildNativeFilterChain(effects, registry, {width, height, fps})` returns the filter text and `blockers` (route those clips to Remotion). Keyframed effect params still need per-segment compilation or the Remotion path (S01:KF-009).
- **ScrubbyNumber**: the inspector uses a local `panels/properties/controls/ScrubbyNumber.tsx` with the WP-2A callback names (`onScrubStart/onScrub/onScrubEnd`, plus `onCommit(fn)` for typed/arrow entry where `fn` maps each base value — needed for relative edits on mixed values). Swap for the `@jasper/ui` one when it lands if its API allows relative typed entry.
