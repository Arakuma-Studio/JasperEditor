# Codebase simplification audit

This page records the earlier audit starting from `0451dcd`. The
[11 October 2026 continuation](wp-notes/slop-audit-2026-10-11.md) reviews the codebase after the parity-program
merge at `12049d8e`; its changes and validation status are recorded separately.

This audit removes demonstrably unused code, duplicated work and unnecessary indirection while preserving supported behavior. Evidence comes from repository-wide caller searches, package entrypoints, dynamic registration paths, before/after data flow and existing behavioral assertions. A low reference count alone was not grounds for deletion.

Validation is complete, including focused follow-ups for every failure. The ledger records per-change evidence, risk and coverage; the validation table records exact full-run results, fixes, retries and gated cases. The layer-cache and session-bridge follow-ups correct bugs demonstrated by behavioral assertions.

### Layer-cache race follow-up

Independent review found an existing race in the active central-cache path: `lookup()` can refresh on-disk metadata after GC scans an old entry but before removal. GC's final check consults the captured age plus the in-memory access index; a disk-only refresh does not update that index. Leased `ensureBake`/`ensureGraded` calls are protected, but bare lookup's documented guarantee also matters.

A deterministic regression replaces the old unconstrained `Promise.all`: retain a real scan snapshot, complete a lookup, then allow cleaning to consume that stale snapshot and assert the returned path survives. The production correction adds `this.core.cache.touch(this.entryDir(key))` synchronously at the start of `markUsed`. The awaited metadata write still persists usage; lease and pending-removal protections remain unchanged.

The same focused command was run before and after that one-line correction:

```sh
pnpm exec vitest run apps/engine/test/layer-bake.test.ts --maxWorkers=1 \
  --testTimeout=120000 --hookTimeout=120000 \
  -t 'GC keeps leased entries and entries a lookup marks used meanwhile'
```

Before: exit 1, one selected test failed because `expect(existsSync(file)).toBe(true)` received false after a successful lookup. After: exit 0, the selected test passed. Both focused runs filtered out the other 13 cases. The captured results are `/tmp/jasper-slop-layer-gc-red.log` and `/tmp/jasper-slop-layer-gc-green.log`. The subsequent full layer suite passed all 14 cases (`/tmp/jasper-slop-layer-suite-final.log`). The before/after result demonstrates the old behavior was incorrect and the minimal fix protects the specified interleaving.

## Safeguards and test decisions

- Keep security, untrusted-document validation, immutable ownership boundaries, atomic persistence, cancellation, partial-file cleanup, model checksums, license restrictions and remote shell quoting. Unreachable constructor modes were removed only after every construction path was traced.
- Keep dynamic boundaries: lazy panel registration, extension/command contracts, tracking functions serialized into workers, warp/stream `.toString()` kernels, generated shader names and project scaffolds. A normal import search alone cannot prove these dead.
- Keep meaningful fallback distinctions: native/Remotion/fframes, browser/GL capabilities, font/engine absence, storage failures, PWA navigation versus streaming/range requests, and pre-module theme bootstrap. Similar sprite lookups differ in epsilon behavior; quad centroid and diagonal intersection are different operations.
- Keep independent test oracles and native/browser implementations. GL compilation/pixel tests are not substitutes for CPU schema checks; API integration/OS clipboard/persistence/concurrency tests establish different boundaries than unit tests. Do not collapse fixtures onto the implementation they verify.
- Remove tests only where they solely exercised removed, production-unused helpers. Numerical assertions were redirected to active behavior; cache assertions moved to the active GC path. No E2E scenario was deleted. No gate was silently enabled or disabled by the shared browser harness.
- Keep documented compatibility surfaces such as resolveAudioFades and Autosaver.saving, live session clock injection, published WASM exports, benchmark baselines, measured numerical explanations and TODOs documenting actual missing functionality.
